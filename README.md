# Quaver Music Flatpak 打包仓库

名字叫作 Quaver Fuck GNOME and Flathub 仓库一大原因是 GNOME 那模糊不清，左右脑互搏的 LLM 政策，影响到了自己的子公司 Flathub LLC，而 Flathub 从不支持 Flatpak 打包使用 LLM 工作，变成了整个软件都不允许有 LLM 介入，所以该打包仓库名字叫操你妈的 GNOME 和 Flathub。
